# Neovim Configuration

Personal Neovim setup using [lazy.nvim](https://github.com/folke/lazy.nvim).

## Key Features
- **LSP & Completion:** `nvim-lspconfig`, `mason.nvim`, `blink.cmp`, `lsp_signature.nvim`.
- **Syntax & Highlighting:** `nvim-treesitter` (C++, Lua, Markdown, LaTeX, etc.).
- **Fuzzy Finder & Explorer:** `telescope.nvim`, `neo-tree.nvim`.
- **Git & Diffs:** `diffview.nvim`.
- **Markdown & Diagrams:** `render-markdown.nvim`, `diagram.nvim`, `image.nvim`.
- **AI Assist:** `copilot.lua` (ghost text).
- **Theme:** `tokyodark.nvim`, `nightfox.nvim`, `kanagawa.nvim`.

## Requirements
- Neovim >= 0.11
- C compiler (`gcc` or `clang`)
- `tree-sitter-cli`
